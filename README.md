# Data Analysis Project 📊

Este repositorio contiene un análisis de datos simple usando Python, `pandas` y `matplotlib`.

## 📌 Descripción
El objetivo de este proyecto es realizar un análisis básico de ventas mensuales y visualizar los datos en un gráfico.

## 🔧 Requisitos
Para ejecutar este proyecto, necesitas tener instalado:

- Python 3.x
- Pandas
- Matplotlib

## 🚀 Instalación
Clona el repositorio y ejecuta el script:

```bash
git clone https://github.com/tu-usuario/data-analysis-project.git
cd data-analysis-project
pip install pandas matplotlib
python analysis.py
